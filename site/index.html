About this demo

This is a static click-through of the Dietrich terminal interface. Every action is simulated against sanitized fixtures — nothing is read, written, or sent anywhere.

The real application is a local CLI and Textual TUI for inspecting document protection, removing soft locks, and recovering open passwords on documents you are authorized to modify.

  • Soft locks — editable flags; removed side-by-side, original untouched.
  • Open passwords — verified explicitly or recovered with bounded, local methods.
  • IRM / Purview — always fails closed; a valid license is required.
