# Bundled visual assets

Pixelify Sans and VT323 are bundled from the Google Fonts repository under their accompanying SIL Open Font Licenses. No remote font is loaded at runtime.

- pixelify-sans.ttf: https://raw.githubusercontent.com/google/fonts/main/ofl/pixelifysans/PixelifySans%5Bwght%5D.ttf
- pixelify-OFL.txt: https://raw.githubusercontent.com/google/fonts/main/ofl/pixelifysans/OFL.txt
- vt323.ttf: https://raw.githubusercontent.com/google/fonts/main/ofl/vt323/VT323-Regular.ttf
- vt323-OFL.txt: https://raw.githubusercontent.com/google/fonts/main/ofl/vt323/OFL.txt

locksmith-atlas.png was generated with the built-in image-generation tool from the approved Dietrich 8-bit design. It contains three decorative states, with all application text and controls implemented separately.
